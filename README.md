# Minimal Christian Wedding Website

A refined, single-page Christian wedding invitation with subtle cross, Scripture, ceremony and reception details.

## Run
Open `index.html` directly in your browser. No npm or build tools needed.

## Personalize
Edit the `wedding` object at the top of `script.js`. Replace the sample names, dates, venues, Google Maps URLs and family message.

## Deploy to Vercel
Upload the folder to a GitHub repository and import it in Vercel as an **Other** framework/static website. No build command is needed.

Uses Google Fonts (internet required for the custom typography); fallback fonts are included.
